## Technologies Used
* HTML5 & CSS3
* Java Servlet (Jakarta / Javax Servlet API)
* JavaServer Pages (JSP)
* GlassFish Server

## How to Run the Application
1. Clone this repository or download the source code.
2. Open the project in Apache NetBeans.
3. Ensure **GlassFish Server** is configured and running in your IDE.
4. Right-click the project and select **Run**.
5. The application will open automatically at `http://localhost:8080/CSC584-Individual-Assignment-1/index.html`.
